# .impeccable — Design Context

## Design Context

### Users
Jugadores activos de D&D 5e y Dungeon Masters que consultan su hoja de personaje durante sesiones presenciales. Uso móvil, principalmente una mano, en ambientes de poca luz. Prioridad absoluta: acceder a stats y recursos rápido sin fricciones. Tolerancia cero a pantallas lentas o saturadas.

### Brand Personality
**Aventurera · Clara · Cálida**

Evoca la estética analógica de los juegos de rol de mesa: pergamino, cuero, bronce, tinta. Sin aspecto tecnológico ni corporativo. Como un grimorio bien diseñado que cabe en el bolsillo.

Emoción objetivo: confianza y familiaridad — como sostener tu hoja de personaje favorita pero en digital.

### Aesthetic Direction
- **Dark mode primario**: fondo negro cálido (#1A1510), textos pergamino (#F2E8D9), acentos dorado/bronce
- **Light mode**: paleta de pergamino claro, tinta oscura, acentos cálidos
- Tipografía serif para títulos y headings (Cinzel/MedievalSharp), Inter para body y stats
- Stats y números en grande — legibilidad > decoración
- Espaciado generoso, sin saturar pantallas
- Iconografía funcional (Ionicons), no decorativa
- Anti-referencias: glassmorphism, gradientes morados, UI crypto/IA, dashboards corporativos, D&D Beyond exacto

### Design Principles
1. **Legibilidad primero** — Si no se puede leer de un vistazo durante el combate, no sirve.
2. **Economía de pantalla** — Cada píxel gana su lugar. Nada superfluo.
3. **Calidez táctil** — Sensación de objeto físico bien construido, no pantalla de software.
4. **Jerarquía clara** — El número más importante de la pantalla se ve sin buscar.
5. **Consistencia gestual** — Patrones de tap, swipe y press consistentes en toda la app.

### Component Conventions
- `AppScreen`: SafeAreaView + ScrollView con padding horizontal de 16px
- `StatCard`: 80x80px mínimo, número grande, label caption
- `SkillRow`: 44px altura mínima, dot de proficiencia, bonus a la derecha
- `PrimaryButton`: 52px altura, fondo dorado (#C8922A), texto bold 16px
- `ResourceCounter`: controles +/- >= 44px, valor actual/máximo visibles
- Todos los touch targets >= 44px (WCAG mobile)
- `accessibilityLabel` en todos los botones de icono

### Tech Stack
- React Native + Expo + TypeScript (strict)
- Expo Router (file-based navigation)
- expo-sqlite (local-first)
- TanStack Query (SRD API + cache)
- Zustand (UI state)
- expo-secure-store (secrets/tokens)
- ESLint + Prettier + Zod
